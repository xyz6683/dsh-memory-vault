# 发布操作手册（照抄即用）

> 本地已就绪：代码已提交（`fa1fda8`）、已打 tag `v0.1.0`、lockfile/CI/双语 README 齐全。
> 剩下都是 GitHub 与插件目录的操作，逐条执行即可。

## 1. 创建公开 GitHub 仓库

1. 打开 https://github.com/new
   - Repository name：`dsh-memory-vault`
   - **Public**（插件目录要求公开）
   - 不要勾选 README/.gitignore（本地已有）
2. 推送方式（**按「双远端推送 SOP」，2026-11-02 已实测成功**）：

```bash
cd <本地仓库目录>   # 例如 ~/dsh-memory-vault
./scripts/publish.sh
```

> 脚本已按 SOP 固化：remote 名 `github`、URL 走 **ssh.github.com:443**（22 端口被墙是首次推送失败的真正原因，SSH key 本身没问题）；沙盒/不可写 known_hosts 环境自动配 `core.sshCommand` 指向 /tmp。脚本最后用 `git ls-remote` 自校验远端 HEAD 与本地一致。
> 可选 Gitee 镜像：`git remote add gitee git@gitee.com:<gitee用户名>/dsh-memory-vault.git && git push gitee main`

3. 验证 CI：打开仓库 Actions 页，等 `CI` workflow 变绿（typecheck + 28 tests + build）。

## 2. 打 dsh-plugin topic（让 dshplugin.store 自动收录）

1. 仓库首页 → 右上角 ⚙️（About 区域）→ Topics 输入 `dsh-plugin` 回车保存。
2. 顺带填 About 描述：`Local-first long-term memory & personal-profile plugin for DeepSeek Harness`。
3. dshplugin.store 按 GitHub topic 定期同步（上次同步 2026-10-30），收录后可在其分类「Memory」中检索到。

## 3. 提交 dshplugins.com 人工审核

1. 打开 https://dshplugins.com/submit （需要站点登录）。
2. 填仓库 URL：`https://github.com/xyz6683/dsh-memory-vault`。
3. 提交文案（可直接复制粘贴）：

   - **插件名**：dsh-memory-vault
   - **一句话描述（英文）**：Local-first long-term memory and personal-profile plugin for DeepSeek Harness — structured memories (SOP / preference / lesson / decision), confirmation-gated automatic extraction, hybrid-ranked cross-session recall with git-branch scoping, per-domain personal profile analysis, Markdown export and a built-in Web panel.
   - **一句话描述（中文）**：本地优先的长期记忆与个人画像插件：结构化记忆（SOP/偏好/经验/决策）、确认闸门自动提炼、混合排序跨会话召回（含 git 分支作用域）、按领域聚合的个人画像、Markdown 导出与内置 Web 面板。
   - **安装命令**：`dsh plugin --profile web add github:xyz6683/dsh-memory-vault`（或本地目录方式，见 README）
   - **前置条件**：DeepSeek Harness（0.2.0-rc.2+）、Node.js ≥ 22.19；无外部服务、无凭据要求
4. 审核要求自查（我们已全部满足）：
   - ✅ README 有精确安装步骤（`dsh plugin --profile web add "$PWD"` + 验证命令）
   - ✅ 前置条件 / 权限（0600、trustedHosts）/ 凭据（无外部凭据）/ 支持平台（macOS/Linux/Windows 通用）/ 已知限制 均写明
   - ✅ 规范仓库 URL，非 fork、非重复
5. 管理员审核通过后：详情页展示安装命令 + README 快照 + 推荐按钮。

## 4. 发布后的版本迭代

```bash
# 改代码 → npm run check 全绿 → 提交推送 → 打 tag
git add -A && git commit -m "feat: ..."
git push origin main
git tag -a v0.2.0 -m "v0.2.0 ..." && git push origin v0.2.0
```

使用者在 dshplugin.store 看到新 tag 即知可升级；本地用户升级：`cd <插件目录> && git pull && npm run check` 后重启 dsh web。
