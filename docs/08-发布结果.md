## 六、复盘：这个项目教给学员的五件事

1. **调研省返工**：三家之长拼出起点，躲掉两个已知大坑（全量注入膨胀、依赖模型自律）。
2. **发布前审查救场**：宿主内置 `vault_*` 命名空间冲突，发布前重命名一次 sed，发布后重命名就是事故。
3. **用户的记忆库是排障资产**：22 端口被墙的真相不在报错里，在用户记忆库的「双远端推送 SOP」里——这正是本插件「沉淀最优操作」价值的自证。
4. **闸门是信任设计，且要随真实使用迭代**：三档闸门 → 用户实测反馈「agent 擅自写是噪音」→ 新增 `mvault_propose` 提议工具。产品决策贯穿全程。
5. **公开前的隐私审计不可省**：一次 grep 抓出错误 org、本机路径、key 命名三处问题，全在公开前抹除。
